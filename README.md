# Giveaway Bot — розыгрыши для Telegram-каналов

Бот публикует в канале пост с кнопкой «✅ УЧАСТВОВАТЬ В КОНКУРСЕ (N)», при нажатии проверяет подписку
на все каналы из условий и в конце случайно выбирает победителей (по умолчанию 20).
Подходит для любого канала: всё настраивается в личном чате с ботом, без правки кода.

## Как это работает

1. Организатор пишет боту `/new` и проходит 5 шагов: канал публикации → текст/картинка поста →
   каналы обязательной подписки → число победителей → дата итогов (или «вручную»).
2. Бот публикует пост с кнопкой. Нажавший кнопку попадает в участники, только если подписан на все каналы;
   иначе видит окно со списком каналов, на которые не подписан.
3. При подведении итогов бот перемешивает участников (`random.SystemRandom`) и **повторно проверяет подписку**:
   отписавшиеся после нажатия кнопки не выигрывают. Итоги публикуются ответом на пост, кнопка закрывается.
4. В `/list`: статистика, выгрузка участников в CSV, подведение итогов, запасной победитель.

**Важно:** бот должен быть администратором во *всех* каналах из условий — иначе Telegram не отдаёт
данные о подписке. В канале публикации нужно право «Публикация сообщений», в остальных достаточно любых минимальных прав.

## Переменные окружения

| Переменная  | Обязательна | Описание |
|-------------|-------------|----------|
| `BOT_TOKEN` | да  | токен от @BotFather |
| `ADMIN_IDS` | нет | Telegram ID через запятую, кому можно создавать розыгрыши. Пусто — любой админ своего канала |
| `TZ_NAME`   | нет | часовой пояс для даты итогов, по умолчанию `Asia/Tashkent` |
| `DB_PATH`   | нет | путь к SQLite. На Railway с Volume определяется автоматически |

## Локальный запуск

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # вписать BOT_TOKEN
python main.py
```

## Деплой: GitHub + Railway

### 1. Создать бота
1. В Telegram откройте @BotFather → `/newbot` → задайте имя и username → скопируйте токен.
2. Узнайте свой Telegram ID (например, у @userinfobot) — пригодится для `ADMIN_IDS`.

### 2. Залить код на GitHub
1. На github.com создайте **приватный** репозиторий, например `giveaway-bot` (без README).
2. В папке проекта:
   ```bash
   git init
   git add .
   git commit -m "Giveaway bot"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/giveaway-bot.git
   git push -u origin main
   ```
   Файл `.env` в репозиторий не попадёт (он в `.gitignore`) — токен хранится только в Railway.

### 3. Развернуть на Railway
1. Зайдите на railway.com, войдите через GitHub.
2. **New Project → Deploy from GitHub repo** → выберите `giveaway-bot`
   (при первом разе Railway попросит доступ к репозиторию).
3. Откройте сервис → вкладка **Variables** → добавьте `BOT_TOKEN` (и при желании `ADMIN_IDS`, `TZ_NAME`).
4. **Подключите Volume** — без него база участников сотрётся при каждом передеплое:
   правый клик по сервису на холсте проекта (или кнопка **Create → Volume**) → привяжите к сервису →
   Mount path: `/data`. Бот сам начнёт хранить базу в `/data/giveaway.db`.
5. Нажмите **Deploy**. Команда запуска (`python main.py`) уже прописана в `railway.json`.
6. Вкладка **Deployments → View logs**: должна появиться строка `Run polling for bot @ваш_бот`.

Примечания:
- Домен/порт не нужны: бот работает через long polling.
- Количество реплик — строго **1** (две копии с одним токеном будут конфликтовать).
- Каждый `git push` в `main` автоматически пересобирает и перезапускает бота.
- Railway платный после пробного кредита (тариф Hobby); боту хватает минимальных ресурсов.

### 4. Запустить розыгрыш
1. Добавьте бота администратором в свой канал и во все каналы-партнёры из условий.
2. Напишите боту `/start`, затем `/new`.
3. Проверьте: нажмите кнопку под постом с аккаунта, не подписанного на один из каналов, — должен быть отказ.
4. Итоги — автоматически по дате или `/list` → розыгрыш → «Подвести итоги сейчас».

## Структура

```
main.py             запуск, планировщик автоподведения итогов
config.py           переменные окружения
db.py               SQLite: розыгрыши, участники, победители
services.py         проверка подписок, счётчик на кнопке, выбор победителей
handlers_public.py  кнопка «Участвовать»
handlers_admin.py   /new, /list, итоги, CSV
```
